# Strawberry Car · 草莓采摘机器人

基于 **STM32F407 + FreeRTOS + K210** 的自主草莓采摘小车。
红外巡线行驶 → 识别岔路 → 转弯进入草莓区 → 超声波停车 → K210 视觉判定成熟度 → 倒车返回主赛道。

> 🏆 全国大学生嵌入式芯片与系统设计竞赛 · ST 赛道 · **中部赛区二等奖**

## 项目概述

小车在一条带岔路的赛道上自主运行，核心要解决的问题是：
**在没有全局定位的前提下，判断"该在第几个岔口停下、眼前的草莓该不该摘"。**

为此把任务拆成三层：

| 层 | 承担者 | 职责 |
|----|--------|------|
| 运动控制层 | STM32F407 | 四轮闭环调速、巡线、避障、状态机调度 |
| 感知层 | K210 | YOLOv2 草莓检测（成熟/未熟），输出结构化坐标 |
| 决策层 | STM32 状态机 | 岔路判定、Zone 匹配、采摘/跳过决策 |

K210 只负责**提供检测数据**，不参与决策；所有状态跳转都在 STM32 侧执行，
保证控制回路的实时性与可复现性。

## 系统搭建

### 硬件构成

| 模块 | 型号 | 接口 | 作用 |
|------|------|------|------|
| 主控 | STM32F407VET6 | — | 运动控制 + 状态机 |
| AI 视觉 | K210 (Maix) | UART1 @115200 | 草莓成熟度检测 |
| 电机驱动 | TB6612 ×2 | TIM1 CH1~4 (PWM) | 四轮独立调速 |
| 编码器 | 增量式 ×4 | TIM5/4/2/8 正交解码 | FL / BL / FR / BR 测速 |
| 循迹 | TCRT5000 ×6 | PE0~PE5 (DO) | 黑线巡线 + 岔路识别 |
| 避障 | HC-SR04 | GPIO + 定时器 | 前方障碍测距 |
| 姿态 | MPU6050 | I2C1 | 航向角积分，辅助转角精算 |
| 显示 | OLED SSD1315 | I2C2 | 状态与草莓计数 |
| 调试 | USB-TTL | USART1 | VOFA+ 波形 / 上位机指令 |
| 遥控 | HC-06 | UART4 + UART5 | 蓝牙指令通道 |

### 软件架构（FreeRTOS 四任务）

| 任务 | 优先级 | 栈 | 周期 | 职责 |
|------|--------|-----|------|------|
| `Task_PID_Ctrl` | AboveNormal | 512 | 10 ms | 传感器采集 + 状态机 + 四轮 PID 闭环 |
| `Task_Vision` | Normal | 512 | 帧驱动 | UART DMA+IDLE 解析 24B 视觉帧 |
| `Task_Sensor` | BelowNormal | 256 | 20 ms | 超声波测距、红外采样 |
| `Task_OLED` | Low | 256 | 100 ms | 显示刷新、状态上报 |

> ⚠️ **I2C 总线争用**：OLED 单次刷屏会独占 I2C 总线约 100 ms，
> 期间 MPU6050 读取会失败。解决方式是**把陀螺仪迁到独立的 I2C1**，
> 与 OLED（I2C2）物理隔离，避免"刷屏时姿态数据跳变"。

### 引脚速查

```
编码器   TIM5=FL   TIM4=BL   TIM2=FR   TIM8=BR
电机PWM  TIM1_CH1~4  →  TB6612
方向脚   FL:PD0/PD1  FR:PD2/PD3  BL:PD4/PD7  BR:PD8/PD9
红外     PE0~PE5（DO=0 压黑线）
视觉     K210 UART1 ↔ STM32（IO7=TX / IO6=RX）
```

## 功能实现

### 1. 四轮闭环调速

每 10 ms 对四轮各跑一次**增量式 PID**（Kp=0.25 / Ki=0.05 / Kd=0.06）：

```
ΔU(k) = Kp·[e(k) − e(k−1)] + Ki·e(k) + Kd·[e(k) − 2e(k−1) + e(k−2)]
```

四轮共用一组参数，围绕"四轮独立闭环"做了这些工程处理：

- **积分抗饱和**：PWM 输出已达上下限时抑制同向积分项累积，避免退出饱和后的过冲。
- **测速 EMA 滤波**（α=0.3，可在线调）：编码器 10 ms 采样的量化噪声很大，
  直接进 PID 会让微分项剧烈抖动，先做一阶低通再送入计算。
- **目标斜坡**：`ramp_target` 按步长逼近设定值，避免目标突变造成电流冲击；
  斜坡归零且速度接近静止时直接锁死输出，防止静止微振。
- **右后轮摩擦前馈**：BR 轮静摩擦死区明显，纯 PID 在低速段会"爬行"。
  按其目标方向叠加固定推力（默认 40，PWM 量纲），越过死区后仍交给 PID 精调。
- **堵转保护**：某轮误差持续超限 500 ms 判定堵转并切断输出，防止堵转烧电机。

差速转向由 `Chassis_DiffTurn(base, diff)` 对左右侧分别加/减同一差速量实现，
原地转向则左右反向对称出力。

### 2. 巡线与岔路识别

6 路 TCRT5000 等间距排列（总宽 10 cm，中心索引 2.5）。
取所有压线传感器的**位置索引算术平均**作为线心，与中心求差得到偏离量：

```
偏移 = (Σ 压线传感器索引) / 压线传感器数 − 2.5
转向 = LINE_KP × 偏移        // LINE_KP = 0.06
```

丢线时让偏移量按 `×0.95/帧` 衰减（约 1 s 趋近直行），
避免全白时沿用旧值导致原地转圈。

**岔路判定**：连续 3 帧 6 路**全部压黑**即确认为岔路口（`JUNCTION_CONFIRM_FRAMES`），
之后前进 13 cm 让车体几何中心对准分支线，再原地转弯进入。
出岔路后 2 s 内抑制重触发，防止在路口抖动误判。

### 3. 岔路采摘流程

```
BRANCH_ENTER    原地转弯进入分支线
BRANCH_FOLLOW   沿分支线前进，超声波持续监测
BRANCH_JUDGE    距离 < 23cm 连续 5 帧 → 停车，采集 300 帧视觉数据（3s）
BRANCH_REVERSE  按编码器直线倒车，返回主赛道
```

**判定策略**：停车后在 3 秒窗口内累计 K210 的检测结果，
按面积过滤掉 `< 2` 的噪声框（新模型输出框偏小，这个阈值是从 5 调下来的），
再按类别统计成熟/未熟数量，只有**成熟且面积达标**的草莓才计入采摘。

### 4. K210 视觉链路

YOLOv2 · 224×224 · 双类别（成熟 / 未熟）· kmodel 约 1.86 MB。

K210 端把检测结果压进 **24 字节定长帧**（5 目标槽 + XOR 校验 + 帧头帧尾），
STM32 端用 **UART DMA + IDLE 中断**整帧接收，零 CPU 轮询开销。
目标按 X 升序排列后发送，下位机无需重排。

> 模型经过 4 轮迭代，通过**按数据集重聚类 anchor** 把验证集准确率从 4.4% 提升到 66.7%。
> 完整的模型谱系、指标对比与协议细节见 **[`k210/README.md`](k210/README.md)**。

### 5. 超声波避障（右绕回线）

急停 → 倒车 5 cm → 原地右转 90° → 前进 25 cm → 左转 135° 斜向对线 → 慢速前寻找回黑线。
斜向回线而不是直角回归，是为了让红外阵列以**小夹角**接近黑线，避免大角度冲过。

### 6. 调试链路

- **VOFA+ JustFloat**：8×float = 32 B，100 Hz 上报四轮速度/目标/PID 输出，实时看波形整定参数。
- **文本命令协议**：`W0~W3` 单轮调试、`P/I/D` 在线改参、`T` 定时运动、`M0~M9` 状态切换、`F` 强制直行。
- **car-studio 上位机**：实时轨迹、状态机可视化、录制回放、参数方案对比。
  见 → [`devtools/car-studio`](https://github.com/silvamafalda966-svg/devtools)

## 编译与烧录

1. Keil MDK 打开 `MDK-ARM/Strawberry_car.uvprojx`
2. Build（F7）→ 通过 ST-Link 下载（F8）
3. K210 侧：把 `k210/main.py` 与 `k210/model/model-291870.kmodel` 拷到 TF 卡根目录，插卡上电
4. 串口工具连接 USART1（115200）可看到 VOFA+ 数据流

> 上赛道前需先实测校准三个常量（见 `BSP/Inc/chassis.h` 顶部注释）：
> `ENC_PER_CM`（直线里程）、`TURN90_TOTAL_ENC`（原地 90°）、`TURN180_TOTAL_ENC`（掉头）。
> 这些值依赖地面摩擦与电池电压，换场地必须重测。
